**Проект "Объявитус**

Автор: Собственный проект.

Цель: Тренировка. Отработка навыков.

Технологии: JS, Vue.js

Описание: Данным проектом хотел реализовать доску объявлений.

Реализовано:
- Авторизация и регистрация через API Supabase.io используя email и пароль;
- ![авторизация](https://user-images.githubusercontent.com/61217980/132994301-d430f44b-bad4-4987-a07c-65c2b7a07b1d.gif)
- Отображение всех объявлений на главной странице путем запроса к БД (Database от Supabase.io)
- Маршрутизация по страницам через vue-router;
- Страницы: избранных товаров, собственно созданных товаров, сообщений, личных данных, создания и редактирования объявления;
- Создание/редактирование объявления;
- Добавление объявления в избранное и удаление его из него;
- Добавление информации о количестве просмотров объявления;
- Изменение статуса объявления (закрытие с указанием причины, возобновления и отправки на повторную модерацию);
- Чат для общения продавца и покупателя на Realtime DB, который обновляет контент при изменении (возможно на web-socket);
- изменение личных данных (номер телефона, аватар, местонахождение);
- загрузка изображения на отдельный Storage, получение ссылки на изображение и добавление ее в текущую БД;

В планах:
- реализация панели администратора для управления объявлениями;
